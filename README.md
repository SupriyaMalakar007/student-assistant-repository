# 🎓 Smart Student Task & Document Assistant

An AI-powered student productivity assistant that helps students manage tasks, analyze academic documents, stay focused, and collaborate with teammates.

## 🚀 Features

### 🤖 AI Assistant
- AI-powered assistance using Google Gemini.
- Ask questions about academic topics and documents.
- Useful for studying, planning, writing, brainstorming, and productivity.
- Secure API-key configuration through environment variables.

### 📋 Smart Task Management
- Quickly create tasks using natural language.
- Set:
  - Priority
  - Subject
  - Due date
  - Time
  - Estimated effort
- Automatically prioritizes tasks.
- Mark tasks as completed.
- Delete tasks.
- Track overdue tasks.
- View completed and active tasks.

### 📄 Document AI
- Paste assignment briefs, syllabi, emails, or lecture notes.
- Analyze documents automatically.
- Calculate:
  - Word count
  - Sentence count
  - Estimated reading time
  - Readability
- Extract important keywords.
- Generate a document summary.
- Detect potential action items.
- Convert detected action items into tasks.
- Generate automatic study cards.
- Upload and extract text from PDF documents.
- Ask AI questions about uploaded/pasted content.
- Generate AI-powered summaries.

### 👥 Team Collaboration
- Create a team with a unique 6-character code.
- Join a team using a team code.
- Share tasks with teammates.
- Claim shared tasks.
- Track team members.
- View the number of members in a team.
- Leave a team and update the member count.
